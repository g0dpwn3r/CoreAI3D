# AI Code Canvas Implementation Plan

## Phase 1 (this phase)
- Add code-block detection utility for Markdown fenced blocks.
- Render each detected code block in a dedicated `CodeCanvas` component.
- Support filename/language display, copy, download, edit, reset, expand/collapse.
- Keep normal text messages unchanged.

## Later phases
- Syntax highlighting and line numbers.
- Unfenced code detection.
- Side-by-side layout and streaming finalization.
- Tests.
